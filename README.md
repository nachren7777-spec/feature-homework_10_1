# Фича для личного кабинета клиента.

## Виджет, который показывает несколько последних успешных банковских операций клиента.

## На данный момент, программа умеет:
1) Маскировать банковский счёт
2) Маскирует номер счёта
3) Вывод дату от строки
4) Сортирует список
5) Выводит список по ключу
