# Фича для личного кабинета клиента.

## Виджет, который показывает несколько последних успешных банковских операций клиента.

## На данный момент, программа умеет:
1) Маскировать банковский счёт
2) Маскирует номер счёта
3) Вывод дату от строки
4) Сортирует список
5) Выводит список по ключу

# Установка
1) Клонируйте репозиторий командой:
`git clone https://github.com/nachren7777-spec/feature-homework_10_1.git`
3) Создайте виртуальное окружение (рекомендуется):
`python -m venv\Scripts\activate/bin/activate # для Linux/Mac`
#### или
`venv\Scripts\activate # для Window`
3) Установите необходимые зависимости:
`pip install -r requirements.txt`

# Использование
1) masks.py - принимает номер карты в 16 символов и номер счёта в 20 символов.
####с Возвращает номер карты, где с 7-13 символы закрыты звёздочкой, а также последние 6 цифр счёта - последние 4 видимыми, а 2 символа перед ними закрывает звёздочкой
2) widget.py - принимает номер карты или счёта, дату: ГГГГ.ММ.ДД, а возвращает замаскированную карту или счёт и дату в формате ДД.ММ.ГГГГ
3) filter_by_state.py - принимает список словарей и возвращает список по введённому значению
4) sort_by_date.py - сортирует список словарей по убыванию

# Тестирование
## Установка через Poetry pytest
`poetry add --group dev pytest`

### Проверка всех тестов командой:
`pytest`

## Code coverage
### Установка:
`poetry add --group dev pytest-cov`

### Запустить тесты с оценкой покрытия:
`poetry run pytest --cov`

### С созданием отчёта о оценке покрытия:
`pytest --cov=src --cov-report=html`

Отчёт будет создан в директории htmlcov/. Откройте файл htmlcov/index.html в браузере, чтобы увидеть:

1) общий процент покрытия;
2) какие файлы покрыты тестами, а какие нет;
3) конкретные строки кода, которые не покрыты тестами.
